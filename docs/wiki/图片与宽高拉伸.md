# 图片与宽高拉伸

## 源图与显示宽高

自有 PNG 放在 `plugins/DialogMenu/images/`，`source` 写相对路径。加载器要求源图宽高为 16 的整数倍，且各在 16..256。禁止越出 images 目录的路径。

符合条件的自有图会生成一个共享 wrapper，由 Shader 独立改变显示宽和高，不必为每一种尺寸复制 PNG。协议尺寸为 1..512，但仍受画布、裁切、命中与原生字体限制，不代表所有尺寸位置都一定可显示。

## 拉伸示例

先下载下面的 16×16 示例源图，放入 `images/demo-panel.png`，再保存布局。该示例图仅用于验证非等比拉伸。

[下载 demo-panel.png](https://raw.githubusercontent.com/wiki/palkane/DialogMenu-RGBA/images/demo-panel.png)

```yaml
schema-version: 1
id: image-demo
canvas: {width: 300, height: 180}
frontend:
  panel:
    type: image
    source: demo-panel.png
    width: 143
    height: 37
    offset: {y: 12}
    tooltip: 同一源图，独立宽高
    actions: 'tell: 点击了拉伸图片'
  label:
    type: text
    content: 图片独立拉伸
    color: '#243247'
    offset: {y: -30, z: 1}
  close:
    type: text
    content: 关闭
    color: '#243247'
    offset: {y: -65}
    actions: close
```

[下载 image-demo.yml](https://raw.githubusercontent.com/wiki/palkane/DialogMenu-RGBA/examples/image-demo.yml)

## 走 Shader 的条件

- 自有源图、无旋转、节点 `opacity: 255`，完整位于画布内，不被裁切。
- 源图各边不超过 254；结合 16 倍数的加载规则，当前可用到 240×240。256×256 源图仍可加载，但不走这条 wrapper 路径。
- 实际请求显示宽高各不超过 512。PNG 自身含透明像素不等于设置了节点 opacity。

不符合 wrapper 条件的自有图会使用已有渲染路径，可能准备不同的图形资源；不要据此承诺所有旋转、透明或裁切变化都不用新包。拉伸是最近邻采样，不是九宫格，边框也会随之变形。

## 原版与 CraftEngine 纹理

| source | 来源 |
| --- | --- |
| `minecraft:item/book` | 内置支持的原版平面纹理，不是任意模型渲染。 |
| `craftengine:image/namespace:id` | 已注册 CE 图片；icon 前缀也是图片入口。 |
| `craftengine:item/namespace:id` | 可解析的 CE 物品纹理，不自动渲染其复杂模型。 |
| `craftengine:texture/namespace:item/path` | CE 资源目录中的原纹理。 |

`reuse-texture: true` 仅用于 image，选择可复用的 CE 原纹理；CE 图集引用会自动使用直引路径。原版与这些直引资源必须**等比、无旋转、无裁切、opacity=255**，不能照上面的自有 PNG 示例非等比拉伸。直引只输出 provider，客户端需要原版或 CE 资源本身。
