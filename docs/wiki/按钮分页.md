# 按钮分页

少量固定页面可直接 `open`；动态列表可由业务端推送外部集合。下面演示最简单、完整且可直接打开的两页，使用不同 page ID，避免把显示文字当状态表达式。

```yaml
schema-version: 1
id: wiki-pages
pages:
  wiki-page-one:
    canvas: {width: 300, height: 180}
    frontend:
      body:
        type: text
        content: 第一页正文
        color: '#243247'
        offset: {y: 30}
      next:
        type: text
        content: 下一页
        color: '#243247'
        actions: 'open: wiki-page-two'
      close:
        type: text
        content: 关闭
        color: '#243247'
        offset: {y: -60}
        actions: close
  wiki-page-two:
    canvas: {width: 300, height: 180}
    frontend:
      body:
        type: text
        content: 第二页正文
        color: '#243247'
        offset: {y: 30}
      previous:
        type: text
        content: 上一页
        color: '#243247'
        actions: back
      close:
        type: text
        content: 关闭
        color: '#243247'
        offset: {y: -60}
        actions: close
```

[下载 wiki-pages.yml](https://raw.githubusercontent.com/wiki/palkane/DialogMenu-RGBA/examples/wiki-pages.yml)

## 更复杂的列表

state 可以保存页码，由业务或已准备的映射控制内容；没有自动执行算术表达式的 `set: page {page}+1`。局部列表、固定页脚或无限数据虚拟化不是原生 flow-list 的能力。

点击翻页可能替换页面身份；不要缓存旧页面点击令牌继续发送。Java binding 只能打开同一 YAML 家族内的页面。
