# 迁移与故障排查

## 移除旧 backend

新版本拒绝 `backend`，连 `backend: {}` 也不接受。把动作、提示和交互权限移到对应的可见 text/image 节点，再删除 backend；不能仅把旧矩形点击区删掉，导致动作丢失。

旧区域覆盖整块按钮而文字较小时，迁移后的点击范围会不同。需要整块命中时，使用带动作的图片元素，不要把 actions 挂在 rectangle 或 group 上。

## 常见问题

| 现象 | 检查顺序 |
| --- | --- |
| 菜单不存在 | 看 reload 最终结果、文件名/id、重复 page ID、open 目标。模板打开 page ID 而非家族 id。 |
| 乱码、方框或缺字 | 确认接收新包、字符在字库中、模板 characters/preview/samples 充分、原字形确实存在。 |
| 位置错乱或编码色可见 | 查 renderer=rgba、匹配包版本，以及其他包是否覆盖核心文字 Shader。 |
| 背景能看但边缘点不到 | 确认动作在 image 或 text 自身；文字不会让背景整块可点。 |
| 纹理直引报错 | 等比、完整不裁切、无旋转、opacity255；非等比拉伸应使用符合条件的自有图。 |
| PNG 无法加载 | 路径在 images 内，宽高16..256且为16倍数，文件是真 PNG。 |
| 超出正文范围 | 实际宽64..512、高≤1024、面积预算、画布倍率，以及逻辑宽高比例。 |
| visible-if 非法 | 必须是 pages 模板，展开后严格 true/false，不写表达式比较。 |
| 绑定失败或没有回调 | 主线程、owner 已启用、玩家在线、同家族、external 键名、当前句柄、元素权限和 callback 动作。 |
| 单击慢了 | 有 double 分支时等待300ms是手势仲裁，不是资源包卡顿。 |

## 报告问题时提供

插件版本与 renderer、服务端/客户端版本、GUI 缩放、文字与画布倍率、最小 YAML 和源图尺寸、reload 最终错误、资源包是否已更新，以及有无其他核心 Shader。显示问题提供截图；点击问题说明准确控件、位置、单/双击和预期动作。不要提交账号、密钥或私有业务数据。
