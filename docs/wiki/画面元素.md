# 画面元素

所有元素写在 `frontend`，键名遵循布局 ID 规则。元素可嵌套在 `group.children` 中。

## 类型与字段

| type | 主要字段 | 说明 |
| --- | --- | --- |
| `group` | `children`、offset、scale | 只组织子元素，不产生自己的图形或点击区。 |
| `rectangle` | width、height、color、opacity | 实心矩形。 |
| `frame` | width、height、thickness、color | 边框，thickness 默认 1。 |
| `line` | width、thickness、color | 线条高度取 thickness。 |
| `text` | content、size、color、alignment、line-width、max-lines | 独立文字，可带动作与提示。 |
| `image` | source、width、height、reuse-texture | 源图片或纹理引用，可带动作与提示。 |

平面图形默认宽高 16；文字默认字号 8。`color` 为引号包住的 `'#RRGGBB'`，默认白色；`opacity` 为 0..255，默认 255。图片的保色路径不把 color 当作通用染色器。

## 分组示例

下面是节点片段，不是独立文件。它把标题与横线一起移动。group 不能直接挂点击动作。

```
header:
  type: group
  offset: {y: 55, z: 1}
  children:
    title:
      type: text
      content: 我的菜单
      color: '#243247'
    rule:
      type: line
      width: 240
      color: '#CBD5E1'
      offset: {y: -18}
```

## 显示与权限

`visible: false` 静态隐藏。动态 `visible-if` 只在[多页模板](https://github.com/palkane/DialogMenu-RGBA/wiki/%E5%A4%9A%E9%A1%B5%E3%80%81%E5%8F%98%E9%87%8F%E4%B8%8E%E6%9D%A1%E4%BB%B6)中处理。菜单顶层 `permission` 控制打开权限；文字/图片上的 `permission` 控制其交互授权，不代替业务插件的交易和数据校验。

没有独立 `backend`，也没有通用三维 `model` 元素。未知字段会报错，不会悄悄当作新功能。
