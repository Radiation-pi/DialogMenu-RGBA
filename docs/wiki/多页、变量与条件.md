# 多页、变量与条件

## 单页与模板是两种结构

普通单页顶层只有布局字段；使用 state、variables、characters、samples、collections、forms 时，应改成下面的 `pages` 家族模板。文件名匹配家族 id，打开命令使用家族中的 page ID。所有文件的 page ID 不能重复。

```yaml
schema-version: 1
id: wiki-app
characters: '龘'
state:
  editing: 'false'
variables:
  mode:
    type: state
    source: editing
    fallback: 浏览
    values: {'false': 浏览, 'true': 编辑}
pages:
  wiki-home:
    canvas: {width: 300, height: 180}
    frontend:
      mode:
        type: text
        content: '当前模式：{mode}'
        color: '#243247'
        offset: {y: 40}
      toggle:
        type: text
        content: 切换编辑
        color: '#243247'
        actions: 'toggle: editing'
      hint:
        type: text
        content: 编辑中
        color: '#2563EB'
        offset: {y: -28}
        visible-if: '{editing}'
      close:
        type: text
        content: 关闭
        color: '#243247'
        offset: {y: -64}
        actions: close
```

[下载 wiki-app.yml](https://raw.githubusercontent.com/wiki/palkane/DialogMenu-RGBA/examples/wiki-app.yml)

执行 `/dialogmenu open wiki-home`。切换后显示“编辑中”，再次切换隐藏。`characters` 仅演示额外字形准备，不要求在画面中出现该字。

## 变量类型

| type | source |
| --- | --- |
| `literal` | 字面字符串，可展开已有变量。 |
| `state` | 当前 state 的键名。 |
| `papi` | PlaceholderAPI 表达式，需相应 expansion。 |
| `skript` | Skript 变量来源，需对应脚本和数据。 |
| `external` | Java binding 提供的数据键；省略 source 时使用变量名。 |

通用字段：`type / source / fallback / preview / max-length / values`。`preview` 用于准备阶段，`fallback` 用于缺失数据，`values` 把离散值映射为显示值。`{player}` 与 `{uuid}` 是内置玩家占位。

> **max-length 不是普通字符串截断**变量上的该字段用于受限数字显示：过长数字会进行缩写或科学计数，非数字可能输出 `-`。不要给玩家名字或任意正文加它来“截字”。表单字段的同名参数则是真正的输入长度限制。

## visible-if

仅模板可用，可用于元素和整个组。表达式展开后必须严格为字符串 `true` 或 `false`，不是 JavaScript、比较表达式或权限表达式。隐藏的元素不保留点击目标。

## samples 与动态几何

模板顶层 `samples` 是变量名到预览值的对象列表；变量必须先声明。可准备不同颜色、图源和几何变体。几何展开支持 offset 的 x/y/z，以及 width、height、size、line-width 等数值字段。

运行时值必须落在已准备资源的范围内。动态换了一张新图、一个新字号或新颜色，不会自动把所有可能值都预生成。多个变量的组合应显式给出代表性 samples，不假定 values 自动穷举笛卡尔积。
