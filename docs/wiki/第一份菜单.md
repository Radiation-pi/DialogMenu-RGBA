# 第一份菜单

新建 `plugins/DialogMenu/layouts/hello.yml`。文件名与 `id` 一致；ID 使用小写字母、数字、`-`、`_`，首字符必须是字母或数字，最长 64 字符。

```yaml
schema-version: 1
id: hello
canvas: {width: 300, height: 180}
events:
  open: 'sound: UI_BUTTON_CLICK-0.5-1'
frontend:
  panel:
    type: rectangle
    width: 300
    height: 180
    color: '#EEF2F7'
  title:
    type: text
    content: '你好，{player}'
    color: '#243247'
    size: 8
    offset: {y: 48, z: 1}
  button-bg:
    type: rectangle
    width: 140
    height: 28
    color: '#D9E5F7'
    offset: {y: -12}
  button:
    type: text
    content: 点击打招呼
    color: '#243247'
    offset: {y: -12, z: 1}
    clickable: true
    tooltip: 向自己发送消息
    actions:
      all: 'sound: UI_BUTTON_CLICK-0.5-1'
      left: 'tell: 你好，{player}！'
  close:
    type: text
    content: '×'
    color: '#243247'
    offset: {x: 132, y: 72, z: 2}
    actions: close
```

[下载 hello.yml](https://raw.githubusercontent.com/wiki/palkane/DialogMenu-RGBA/examples/hello.yml)

## 加载与打开

1. 保存文件，管理员执行 `/dialogmenu reload`，等待成功提示。
2. 完成资源包更新，让客户端接收新包。仅改 YAML 不等于客户端已拿到字库。
3. 玩家执行 `/dialogmenu open hello small`。
4. 点击文字“点击打招呼”，应听到声音并收到问候；点击“×”关闭。

> **点击跟随文字，不跟随背景**矩形只是底色，不是独立按钮区域。本例文字带动作，矩形边缘不应执行它。要做整块可点击按钮，可使用带动作的 `image`。

Esc 默认禁用，应保留可见关闭入口。界面不是整张文字截图：背景和文字始终是不同元素。
