# 动作与事件

动作格式通常为 `'类型: 参数'`；无参数动作直接写名称。多个动作按字符串列表配置。命令参数不需要前导 `/`。

## 动作表

| 动作 | 用途与注意 |
| --- | --- |
| `tell: 文本` | 向当前玩家发送消息。 |
| `sound: UI_BUTTON_CLICK-0.5-1` | 声音 name-volume-pitch；音量 0..16、音高 0..2，也可用命名空间声音 ID。 |
| `command: spawn` | 先关闭菜单，再由玩家执行命令。 |
| `command-in-place: balance` | 不预先关闭菜单，按玩家身份执行。 |
| `console: ...` | 先关闭，再执行控制台命令；只能由可信管理员维护，不能交给不可信用户编辑。 |
| `open: page-id` | 打开已加载页面；不存在的目标在加载时被拒绝。 |
| `back` | 返回导航历史中的页面；无历史时关闭。 |
| `close` | 关闭当前菜单并清理会话。 |
| `return` | 立即结束当前动作列表，不关闭菜单，也不等于 back。 |
| `toggle: editing` | 切换已声明的模板 state 布尔值。 |
| `set: page 2` | 更新已声明的模板 state。 |
| `notice: 文本` | 设置模板 notice 状态供展示。 |
| `entry: collection-id item-id` | 模板集合条目操作；external 集合回传稳定 ID，不是任意物品发放命令。 |
| `callback: inspect` | 向当前 Java binding 回传字符串，由业务插件处理。 |

## 打开与关闭事件

`events.open` 和 `events.close` 只允许 tell、sound，防止导航递归。不能在关闭事件中再 open 页面或执行业务命令。

```
events:
  open:
    - 'sound: UI_BUTTON_CLICK-0.5-1'
  close:
    - 'tell: 已关闭菜单'
```

## 命令与回调如何选择

已有独立命令可以直接用 command。需要绑定会话、业务数据和稳定 ID 时，使用 callback 或 external collection 的 Java 回调。不要在 YAML 中重造一套交易数据库。
